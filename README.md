# Zaunite

Zaunite is an unofficial, fan-made web experience inspired by Tame Impala's *Deadbeat*. It brings together album-inspired visuals, an immersive interactive experience, and a fictional tour page with a demo ticket-booking flow.

The project focuses on a dark visual style, neon-lime accents, and atmospheric presentation.

## Features

- **Album-inspired design** with a dark palette and bold neon-lime details.
- **Immersive experience page** featuring interactive visuals.
- **Tour page** presenting fictional dates and venues.
- **Demo ticket booking** to explore a sample booking flow.
- **Responsive web interface** built with reusable React components.

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Motion
- Lucide React

## Getting Started

### Requirements

- Node.js
- npm

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Utkarsh-git-init/Zaunite.git
   cd Zaunite
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL printed in your terminal.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Build the project for production |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
